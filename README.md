# 🍃 Expira Food

**Projeto Integrador | Técnico em Desenvolvimento de Sistemas — Senac**

## Sobre o projeto

O Expira Food é um projeto que busca contribuir para a redução do desperdício de alimentos, conectando estabelecimentos que possuem produtos próximos do vencimento a consumidores interessados em adquiri-los por preços mais acessíveis.

A proposta é desenvolver uma solução tecnológica que incentive o consumo consciente, gere oportunidades de economia e ajude a diminuir o descarte desnecessário de alimentos.

## 🎯 Objetivo

Desenvolver uma plataforma que facilite a divulgação e a comercialização de alimentos próximos do vencimento, promovendo sustentabilidade, economia e responsabilidade social.

## 💡 Funcionalidades previstas

- Cadastro e login de usuários.
- Cadastro de estabelecimentos.
- Divulgação de ofertas.
- Consulta de produtos disponíveis.
- Visualização de informações dos produtos.
- Gerenciamento de pedidos.
